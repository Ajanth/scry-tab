# ScryTab Product Feature Inventory

This is a product-surface inventory for stripping ScryTab down. Source references are relative to the repository root. The list focuses on user-visible behavior, preferences, permissions, business logic, and support surfaces; internal UI kit helpers are referenced only when they directly shape product behavior.

## Product Identity And Launch

- ScryTab is a macOS window switcher. It runs as a normal Cocoa app with a menubar item, secondary windows, and a floating switcher panel rather than a document UI. References: `README.md`, `src/App.swift`, `src/main.swift`, `src/Menubar.swift`, `src/switcher/SwitcherSession.swift`.
- The app prevents App Nap with a user-initiated activity so switching stays responsive. Reference: `src/App.swift`.
- On launch, the app initializes preferences, background work queues, permission checks, menubar, main menu, switcher panels, event observers, update handling, and usage stats pruning. Reference: `src/App.swift`.
- Release builds prompt the user to move the app into `/Applications`. The move is a custom implementation (replacing the LetsMove pod): it skips when the user has opted out, switches to an already-running instance if the destination app exists, strips the `com.apple.quarantine` xattr after copying, and detaches the source DMG after relaunch. References: `src/App.swift`, `src/util/MoveToApplicationsFolder.swift`.
- At launch the app disables macOS relaunch-on-login so it is not re-launched by the system "Reopen windows when logging back in" behavior. Reference: `src/App.swift`.
- The app installs SIGTERM, SIGTRAP, and uncaught-exception handlers that perform an emergency clean exit: they restore native Command-Tab, log, print a stack trace, and exit. SIGKILL cannot be intercepted. Reference: `src/main.swift`.
- Reopening the app from Finder/Dock shows Settings. Reference: `src/App.swift`.
- A user-initiated cold launch from Finder, Dock, or an app launcher opens General Settings while the menu bar icon is hidden, unless onboarding or an explicit pending Settings route takes precedence. Login-item, internal-restart, and Sparkle-update relaunches stay silent: the LoginAgent plist and `App.restart()` pass `--scrytab-silent-launch`, and Sparkle records the one-shot `scrytab.pendingSilentLaunch` default for both automatic and manual "Install and Relaunch" because its relaunch cannot carry launch arguments. References: `src/App.swift`, `src/macos/LaunchIntent.swift`, `src/macos/LoginItem.swift`, `src/vendors/SparkleDelegate.swift`.
- The first launch presents the onboarding tour once, guarded by `Preferences.initialExperienceShown` (which reads the retained `settingsWindowShownOnFirstLaunch` key); the tour can complete into a Settings route. References: `src/App.swift`, `src/onboarding/OnboardingTourResolver.swift`, `src/preferences/Preferences.swift`.
- Secondary windows persist and restore their window frame where possible. Corrupt persisted frames are caught instead of crashing the app. Reference: `src/App.swift`, `src/macos/api-wrappers/PersistedWindowFrameSpecs.md`.
- On termination, native Command-Tab symbolic hotkeys are restored. Reference: `src/App.swift`, `src/preferences/settings-window/tabs/controls/NativeHotkeyResolver.swift`.

## Required Permissions

- ScryTab uses one permission: Accessibility (required). It is needed to focus, raise, close, minimize, fullscreen, and inspect windows through the AX APIs, and the app cannot proceed without it. The app never requests Screen Recording. References: `src/macos/SystemPermissions.swift`, `src/secondary-windows/permission-window/PermissionsWindow.swift`.
- The permission window has a single Accessibility row with its justification text and a System Settings deep link. Pre-startup launch is gated until Accessibility is granted. References: `src/secondary-windows/permission-window/PermissionsWindow.swift`, `src/secondary-windows/permission-window/PermissionView.swift`, `src/macos/SystemPermissions.swift`.
- Permission polling fires immediately at startup, then every 5 seconds while Accessibility is missing, and every 0.5 seconds while the Permissions window is open. After startup completes, Accessibility revocation is detected by a distributed notification plus a 60 second backstop timer; revocation restarts the app. Reference: `src/macos/SystemPermissions.swift`.

## Menubar And Main Menu

- The menubar status item is optional and carries no icon style selector. `showMenubarIcon` (default `true`) hides it while the status item and its menu stay alive, so Settings and the switcher keep working. macOS menubar removal by Command-drag is allowed, and a removal persists as `showMenubarIcon = false`. References: `src/Menubar.swift`, `src/preferences/MenubarVisibilityPreference.swift`, `src/preferences/settings-window/tabs/GeneralTab.swift`.
- Left click on the menubar item opens the menu. Non-left click shows the switcher for the first shortcut profile (`showUiFromShortcut0`). Reference: `src/Menubar.swift`.
- Menubar commands include Show, Settings, Check for updates, Check permissions, About, Debug tools, Send feedback, and Quit. Reference: `src/Menubar.swift`.
- The app menu's ⌘, item opens ScryTab's own Settings window. It is app-local, not a global shortcut, and it remains a recovery path while the menubar icon is hidden, as does reopening the running app. References: `src/MainMenu.swift`, `src/App.swift`.
- The app builds a full macOS main menu so editing, file, format, window, and help commands behave normally in secondary windows. The menu is disabled while the switcher is active, except the Edit menu can be enabled while search editing is active. References: `src/MainMenu.swift`, `src/switcher/main-window/TilesView.swift`.
- In DEBUG builds, a middle-click (button 2) on the menubar status item toggles the QA menu panel via a local event monitor. References: `src/Menubar.swift`, `src/debug/QAMenu.swift`.

## Core Switcher Session

- The switcher opens from global shortcut profiles, Focus Set direct shortcuts, or the menubar Show command. References: `src/App.swift`, `src/events/KeyboardEvents.swift`, `src/Menubar.swift`, `src/switcher/focus-sets/FocusSetSessionResolver.swift`.
- A fresh summon creates or reuses a `SwitcherSession`, records usage stats, snapshots the active shortcut index, updates screens/spaces, starts search mode if configured, computes window visibility, selects the initial item, then builds the panel synchronously (no display delay or apparition animation). References: `src/App.swift`, `src/switcher/SwitcherSession.swift`, `src/util/UsageStats.swift`.
- Repeating the same shortcut while the switcher is already open cycles selection instead of rebuilding the panel. References: `src/App.swift`, `src/switcher/ATShortcut.swift`, `src/switcher/KeyRepeatTimer.swift`.
- Key-repeat timers support continuous next-window and previous-window cycling. References: `src/switcher/KeyRepeatTimer.swift`, `src/App.swift`.
- The switcher hides immediately if Mission Control is showing all/front windows. On macOS 12+ this state comes from private Dock AX notifications; older systems fall back to a CG window heuristic for untitled Dock windows outside layer 500. References: `src/switcher/state/Windows.swift`, `src/events/DockEvents.swift`, `src/macos/api-wrappers/MissionControl.swift`.
- The switcher is implemented as a non-activating floating panel, ordered above other UI, visible on all Spaces, and hidden without stealing key status from the previously focused window. References: `src/switcher/main-window/TilesPanel.swift`, `src/App.swift`.
- When hidden, the app resets search, usage session state, cursor event taps, trackpad gesture state (when gestures are enabled), context menu state, tooltips, and main menu state. Reference: `src/App.swift`.
- If there are no displayable windows, the panel shows a "No Window" label. Reference: `src/switcher/main-window/TilesView.swift`.
- The selected tile is made first responder for VoiceOver unless the search field is being edited. Reference: `src/switcher/state/Windows.swift`.
- The panel can preserve scroll position across external refreshes, such as window changes while the switcher is open. Reference: `src/App.swift`, `src/switcher/main-window/TilesView.swift`.

## Window Inventory

- ScryTab models each running application and each switchable window, combining Accessibility, CoreGraphics, SkyLight/CGS, and AppKit information. References: `src/switcher/state/Application.swift`, `src/switcher/state/Applications.swift`, `src/switcher/state/Window.swift`, `src/switcher/state/Windows.swift`.
- Applications with no windows can appear as "windowless app" entries, using app launch/activation behavior when selected. References: `src/switcher/state/Window.swift`, `src/switcher/state/Application.swift`, `src/kit/WindowlessAppIndicator.swift`.
- Window titles use a best-effort cascade: AX title, CG window title, then app name. Reference: `src/switcher/state/Window.swift`.
- The app subscribes to application and window AX events for creation, destruction, title changes, minimization, deminimization, resize, move, focus, and activation, rather than polling. References: `src/events/AccessibilityEvents.swift`, `src/events/AxEventRouting.swift`, `src/events/AxEventRoutingSpecs.md`, `src/switcher/state/Window.swift`.
- Slow or unresponsive app/window API calls are scheduled through per-domain schedulers and background queues. References: `src/macos/AXCallScheduler.swift`, `src/macos/CGSCallScheduler.swift`, `src/macos/ProcessCallScheduler.swift`, `src/util/BackgroundWork.swift`.
- Space and screen membership are refreshed reactively on space/screen changes and after show, avoiding blocking SkyLight calls on the hot show path. References: `src/switcher/state/Windows.swift`, `src/events/SpacesEvents.swift`, `src/events/ScreensEvents.swift`, `src/switcher/state/Spaces.swift`, `src/switcher/state/Screens.swift`.
- Tabbed windows always collapse to the frontmost native tab. Inactive tab space information falls back to the active tab sibling because macOS does not reliably report it. References: `src/switcher/state/TabGroup.swift`, `src/switcher/state/Window.swift`, `src/switcher/state/WindowFilterResolver.swift`.
- "Phantom" windows are detected and hidden when they represent invisible or synthetic windows, including no-space windows and CGS visibility mismatches. References: `src/switcher/state/PhantomWindowDetector.swift`, `src/switcher/state/PhantomWindowDetectorSpecs.md`, `src/switcher/state/Window.swift`.
- A window discriminator decides whether each AX window is switchable, applying a baseline size threshold (width > 100, height > 50) plus roughly 19 app-specific rules that accept or reject windows by subrole, role, title, or size for apps like JetBrains/Android Studio, Steam, Adobe Audition/After Effects/Premiere Pro, VLC, AutoCAD, Firefox, IINA, Fusion 360, FL Studio, Keynote, Preview, Books, and others. Reference: `src/switcher/state/WindowDiscriminator.swift`.
- An application discriminator decides whether a process is eligible at all: it rejects XPC processes (via `ProcessInformation` process type) and zombie processes (via `KERN_PROC` sysctl), and special-cases bundle-id-less processes by detecting Passwords.app and the Android Emulator (the latter by matching `qemu-system*` from `KERN_PROCARGS`). References: `src/switcher/state/ApplicationDiscriminator.swift`, `src/macos/api-wrappers/Sysctl.swift`, `src/macos/api-wrappers/HelperExtensions.swift`.

## Filtering, Ordering, And Selection

- Each shortcut profile has independent filters for active app, non-active apps, all apps; visible Spaces, non-visible Spaces, all Spaces; all screens or the screen showing ScryTab; minimized, hidden, fullscreen, and windowless entries; and exceptions. References: `src/preferences/MacroPreferences.swift`, `src/preferences/ShortcutConfiguration.swift`, `src/preferences/settings-window/tabs/controls/ShortcutEditor.swift`, `src/switcher/state/WindowFilterResolver.swift`, `src/switcher/state/WindowFilterResolverSpecs.md`.
- Show/hide filters support three states for minimized, hidden, fullscreen, and windowless entries: show, hide, or show at the end. References: `src/preferences/MacroPreferences.swift`, `src/switcher/state/WindowOrderResolver.swift`, `src/switcher/state/WindowOrderResolverSpecs.md`.
- Window filtering is resolved in a precise order: phantom and exception checks, app/frontmost filters, hidden/windowless/fullscreen/minimized filters, Space/screen filters, and native-tab filters. Reference: `src/switcher/state/WindowFilterResolver.swift`.
- Window ordering modes are recently focused first, recently created first, and alphabetical order. References: `src/preferences/MacroPreferences.swift`, `src/switcher/state/WindowOrderResolver.swift`, `src/switcher/state/WindowOrderResolverSpecs.md`.
- Active search changes ordering so matching windows rank ahead of non-matches by search relevance. Reference: `src/switcher/state/WindowOrderResolver.swift`.
- Selection preserves a stable target across reorders and refreshes. It can restore the default selection after search clear, choose the best match on search change, or clear selection when the target disappears. References: `src/switcher/state/SelectionResolver.swift`, `src/switcher/state/SelectionResolverSpecs.md`, `src/switcher/state/Windows.swift`.
- Initial selection differs by order mode: recently focused mode starts like Command-Tab; other order modes use the last-focused rule when appropriate. Reference: `src/switcher/state/SelectionResolver.swift`.

## Search

- In-switcher search is available to every user. Reference: `src/switcher/main-window/TilesView.swift`.
- Search has three modes: off, editing, and locked. Editing focuses the search field; locked freezes the current result set and returns keyboard focus to tiles. References: `src/switcher/state/SearchModeResolver.swift`, `src/switcher/state/SearchModeResolverSpecs.md`, `src/switcher/main-window/TilesView.swift`.
- While search mode is on, the panel anchors to a frozen top-center point so that narrowing the result set shrinks the panel downward rather than making it jump; the anchor is captured at the panel's tallest extent and reset when search exits. Reference: `src/switcher/main-window/TilesPanel.swift`.
- A shortcut can start the switcher directly in search mode through the "Search" release style. References: `src/preferences/MacroPreferences.swift`, `src/App.swift`.
- The search shortcut toggles editing on/off. The lock-search shortcut toggles between editing and locked when available. Escape can either exit search or close the switcher depending on the entry path. References: `src/switcher/state/SearchModeResolver.swift`, `src/switcher/ShortcutAction.swift`, `src/switcher/main-window/TilesView.swift`.
- Search editing routes arrow keys, Tab, cancel, focus, and lock-search keys while preserving IME marked text and context-menu behavior. Reference: `src/switcher/main-window/TilesView.swift`.
- Ranking normalizes text with case and diacritic folding. Match tiers include exact, text prefix, word prefix, substring, acronym, fuzzy Damerau-Levenshtein, and partial-prefix typo rescue. References: `src/switcher/Search.swift`, `src/switcher/SearchTestable.swift`, `src/switcher/SearchSpecs.md`.
- App-name matches get a slight score boost over window-title matches. Reference: `src/switcher/SearchSpecs.md`.
- Very short queries avoid fuzzy matching, and whitespace-only queries do not match. Reference: `src/switcher/SearchSpecs.md`.
- Search handles CJK text, emoji, punctuation boundaries, and case-sensitive bonuses. Reference: `src/switcher/SearchSpecs.md`.
- Tile labels highlight matching ranges in app/title text. Highlights survive truncation, and the ellipsis can be highlighted if the hidden text contains the match. References: `src/switcher/main-window/TileView.swift`, `src/switcher/main-window/TileTitleView.swift`.

## Appearance And Layout

- The switcher offers two appearance styles selectable in the Appearance tab: App Icons (large app icons in a grid) and Titles (text list). Each style has its own layout. References: `src/preferences/MacroPreferences.swift`, `src/switcher/Appearance.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceTab.swift`, `src/switcher/main-window/TileView.swift`.
- Size options are Small, Medium, and Large. References: `src/preferences/MacroPreferences.swift`, `src/switcher/Appearance.swift`, `src/switcher/AppearanceSpecs.md`, `src/switcher/main-window/TilesView.swift`.
- Effective theme supports Light, Dark, and System. A legacy UI theme enum also contains macOS and Windows 10, but `Preferences.theme` currently always returns macOS. References: `src/preferences/MacroPreferences.swift`, `src/preferences/Preferences.swift`, `src/switcher/Appearance.swift`.
- The panel can appear on the active screen, the screen containing the mouse, or the screen containing the menu bar. Reference: `src/preferences/MacroPreferences.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceTab.swift`.
- Title display can be window title, application name, or application name plus window title. Title truncation can be start, middle, or end. The "Show titles" dropdown and "Title truncation" controls live in the Customize sheet. References: `src/preferences/MacroPreferences.swift`, `src/preferences/settings-window/tabs/appearance/CustomizeStyleSheet.swift`, `src/switcher/main-window/TileTitleView.swift`.
- The switcher supports RTL/LTR layout and navigation-aware row behavior. References: `src/switcher/main-window/TilesView.swift`, `src/switcher/main-window/TileView.swift`.
- The panel uses cached visual-effect background views keyed by the required effect kind. On macOS 26+ the panel uses the regular Liquid Glass path; older systems use `NSVisualEffectView`. References: `src/switcher/main-window/TilesView.swift`, `src/switcher/main-window/TilesPanelBackgroundView.swift`, `src/switcher/Appearance.swift`.
- Tile views are recycled to reduce allocation churn. Reference: `src/switcher/main-window/TilesView.swift`.
- Status icons can indicate hidden, fullscreen, minimized, Space number, and special/windowless states; users can hide status icons and Space number labels. References: `src/switcher/main-window/StatusIconsView.swift`, `src/switcher/main-window/TileView.swift`, `src/preferences/settings-window/tabs/appearance/CustomizeStyleSheet.swift`.
- Tile status/Space-number glyphs are drawn from SF Symbols rendered as font glyphs. A build step subsets the SF font down to only the glyphs ScryTab uses (roughly 98 codepoints, including the named symbols and the runtime-synthesized Space-number variants) to shrink the shipped font. References: `src/switcher/main-window/TileFontIconView.swift`, `src/switcher/main-window/StatusIconsView.swift`, `scripts/assets/subset_font.sh`.
- Windowless app entries show a dedicated indicator with tooltip text explaining the app is running without open windows. References: `src/kit/WindowlessAppIndicator.swift`, `src/switcher/main-window/TileView.swift`.
- Dock labels/badges can be shown on tiles. References: `src/switcher/state/Application.swift`, `src/switcher/main-window/TileView.swift`.
- The Customize sheet includes toggles for hiding status icons, hiding Space number labels, and hiding colored hover circles. Unsupported combinations show an "Applies in other Appearances" placeholder. References: `src/preferences/settings-window/tabs/appearance/CustomizeStyleSheet.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceTab.swift`.
- The switcher panel is ordered out with no fade or other apparition/disparition animation. Reference: `src/switcher/main-window/TilesPanel.swift`.

## Keyboard Controls

- The app supports up to 9 keyboard shortcut profiles. The default shortcut count is 2; minimum is 1 and maximum is 9. References: `src/preferences/Preferences.swift`, `src/preferences/settings-window/tabs/controls/ControlsTab.swift`.
- Each shortcut profile has a "Hold" recorder and an "and press" recorder. The second recorder is constrained by the hold modifier. Recorders do not let Escape cancel recording or Delete clear a shortcut, and modifier-only shortcuts are allowed. Hold recorders are non-clearable and must record modifiers only. References: `src/preferences/settings-window/tabs/controls/ShortcutEditor.swift`, `src/kit/CustomRecorderControl.swift`, `src/kit/CustomRecorderControlSpecs.md`.
- Defaults include a first profile based on Option-Tab and a second profile using the localized key above Tab. References: `src/preferences/Preferences.swift`.
- Additional shortcut profiles beyond the first can be added from Controls. Reference: `src/preferences/settings-window/tabs/controls/ControlsTab.swift`.
- Removing shortcut profiles compacts/copies later slots down so stored settings stay contiguous. Reference: `src/preferences/settings-window/tabs/controls/ControlsTab.swift`.
- Global/local commands include focus selected window, previous window, cancel, search, and close window. References: `src/preferences/Preferences.swift`, `src/preferences/settings-window/tabs/controls/ControlsTab.swift`, `src/preferences/settings-window/tabs/controls/ShortcutsWhenActiveSheet.swift`, `src/switcher/ShortcutAction.swift`.
- Local command matching accepts exact local modifiers or local modifiers plus the active hold modifiers while the switcher is open. Reference: `src/switcher/main-window/TilesView.swift`, `src/switcher/ATShortcut.swift`.
- Shortcut release style can be Focus, Hold, or Search. Focus-on-release focuses the selected window when the hold modifier (or gesture, when enabled) ends; Hold leaves the switcher open; Search starts in search editing. References: `src/preferences/MacroPreferences.swift`, `src/App.swift`, `src/switcher/ATShortcut.swift`.
- Modifier cleanup excludes Fn and unknown bits so matching is robust. Reference: `src/switcher/ATShortcut.swift`.
- The keyboard layer handles out-of-order and missing key events with safety paths to avoid leaving the switcher stuck. References: `src/events/KeyboardEvents.swift`, `src/events/KeyboardEventsSpecs.md`, `src/switcher/ATShortcut.swift`.
- If any configured shortcut uses Escape, a cghid event tap can absorb Escape while the switcher is active so macOS Game Overlay does not intercept it first. Reference: `src/events/KeyboardEvents.swift`.
- The shortcut recorder has a separate validator for macOS-reserved Force Quit chords (`⌘⌥⎋`, `⌘⌥⇧⎋`, and `⌘⌥⇧⌃⎋`) and shows a dedicated warning explaining that ScryTab cannot use them. References: `src/kit/CustomRecorderControl.swift`, `src/kit/CustomRecorderControlTestable.swift`.
- Native Command-Tab and Command-backtick symbolic hotkeys can be disabled while ScryTab owns equivalent shortcuts and restored when no longer needed. References: `src/preferences/settings-window/tabs/controls/ControlsTab.swift`, `src/preferences/settings-window/tabs/controls/NativeHotkeyResolver.swift`, `src/preferences/settings-window/tabs/controls/NativeHotkeyResolverSpecs.md`.
- Arrow-key selection is always enabled and cannot be turned off. Assigning a shortcut that conflicts with the fixed arrow keys is refused. References: `src/preferences/settings-window/tabs/controls/ControlsTab.swift`, `src/kit/CustomRecorderControl.swift`.
- Focusing a selected window always warps the cursor to that window's center. Reference: `src/App.swift`.

## Trackpad Gestures (currently disabled)

> **Disclaimer:** Trackpad gesture switching is present in the codebase but **shipped disabled** via `FeatureFlags.gestures = false` in `src/preferences/Preferences.swift`. While the flag is false, gesture observation does not start, the Controls → Gestures UI and settings route are hidden, `Preferences.nextWindowGesture` always reads as disabled, and navigation/gesture entry points no-op. Re-enable by flipping that flag.

- A separate gesture profile can be disabled or set to 3-finger horizontal swipe, 3-finger vertical swipe, 4-finger horizontal swipe, or 4-finger vertical swipe. References: `src/preferences/MacroPreferences.swift`, `src/preferences/settings-window/tabs/controls/ControlsTab.swift`, `src/events/TrackpadEvents.swift`.
- Gesture triggering imitates native Space swipe thresholds, rejects gestures with too much movement in the wrong direction, and avoids triggering from non-fresh gestures such as a prior two-finger scroll. Reference: `src/events/TrackpadEvents.swift`.
- While the switcher is open from a gesture, further trackpad swipes navigate the selection one row or column without wrapping. Reference: `src/events/TrackpadEvents.swift`.
- Gesture trigger and navigation always perform haptic feedback when the hardware supports it. Reference: `src/events/TrackpadEvents.swift`.
- Scroll-wheel blocking is enabled while gesture switching is active to avoid continuous trackpad scroll leaking into the front app, while mouse wheel behavior is preserved where possible. References: `src/events/TrackpadEvents.swift`, `src/events/ScrollwheelEvents.swift`.
- Settings deep-links to the gesture profile normalize away when gestures are disabled. References: `src/preferences/settings-window/SettingsRoute.swift`, `src/preferences/settings-window/SettingsRouteSpecs.md`.

## Mouse

- Left click on a tile focuses it; clicking outside dismisses; search-field clicks pass through. Reference: `src/events/CursorEvents.swift`.
- Middle/other mouse button on a tile closes the window, or quits the app if the tile is a windowless app. Reference: `src/events/CursorEvents.swift`.
- Pointer hover updates visual hover highlighting only and does not change selection. After keyboard navigation (or a trackpad gesture when gestures are enabled), a 25 px dead zone prevents accidental hover changes until the pointer intentionally moves, and hover updates are suppressed while a context menu is open. The open-menu state is tracked by counting `NSMenu` `didBeginTracking`/`didEndTracking` notifications, and the same signal also suppresses drag operations while a right-click context menu is open. References: `src/events/CursorEvents.swift`, `src/switcher/main-window/TileOverView.swift`, `src/switcher/state/Windows.swift`, `src/events/ContextMenuEvents.swift`.

## Drag And Drop

- The switcher accepts URL/file drops. Dragging over a tile selects it and can arm a delayed auto-focus timer. References: `src/switcher/main-window/TilesView.swift`, `src/switcher/main-window/DragAndDropResolver.swift`, `src/switcher/main-window/DragAndDropResolverSpecs.md`.
- The drag auto-select timer is 2 seconds. Moving the pointer onto a different tile or beyond a 5 px reset radius restarts the timer; it is canceled on drop or exit. Reference: `src/switcher/main-window/DragAndDropResolverSpecs.md`.
- Dropping opens the URLs with the target app bundle. Reference: `src/switcher/main-window/TilesView.swift`.
- Mouse-up events from drags that began outside ScryTab are passed through so the system drop can conclude. References: `src/events/CursorEvents.swift`, `src/switcher/main-window/DragAndDropResolver.swift`.

## Window And App Actions

- Focusing a windowless app launches it by bundle URL when possible, otherwise activates the running app. Reference: `src/switcher/state/Window.swift`.
- Focusing a normal window deminimizes it if needed, fronts the target process/window with private SkyLight APIs, synthesizes a make-key interaction, raises it with AX, and repairs the origin Space front process for cross-Space focus. Reference: `src/switcher/state/Window.swift`.
- Focusing own ScryTab secondary windows uses AppKit window focus directly. Reference: `src/switcher/state/Window.swift`.
- Close uses AX commands. Fullscreen windows are first defullscreened and then acted on after the macOS animation delay. Reference: `src/switcher/state/Window.swift`.
- Quit app (middle-click on a windowless tile, and related paths) protects Finder unless Finder's own Quit menu item is enabled. A second quit request force-terminates the app. Reference: `src/switcher/state/Application.swift`.

## Exceptions

- Exceptions are app rules keyed by bundle ID prefix. Empty bundle IDs and apps without a bundle ID never match. References: `src/switcher/state/ExceptionMatcher.swift`, `src/switcher/state/ExceptionMatcherSpecs.md`.
- Hide rules are Don't hide, Always, When no open window, and Window title contains. Window-title patterns support multiple strings; nil, empty arrays, and empty strings do not match. References: `src/preferences/MacroPreferences.swift`, `src/preferences/settings-window/tabs/ExceptionEditorView.swift`, `src/switcher/state/ExceptionMatcher.swift`.
- Ignore-shortcuts rules are Never, Always, and When fullscreen. A matching ignore rule disables ScryTab global shortcuts while the app is frontmost, and hides the open switcher if disabling becomes active. References: `src/preferences/MacroPreferences.swift`, `src/switcher/state/ExceptionMatcher.swift`, `src/App.swift`.
- The Exceptions settings tab has a sidebar, add/remove controls, "Add a running app" menu, "Add an app from disk" panel, app icons/names, keyboard up/down navigation, and duplicate prevention. References: `src/preferences/settings-window/tabs/ExceptionsTab.swift`, `src/preferences/settings-window/tabs/ExceptionEditorView.swift`.
- Default exceptions hide Finder only when it has no open window, ignore ScryTab shortcuts while fullscreen for Screen Sharing, Microsoft Remote Desktop, TeamViewer, VirtualBox, Parallels, Citrix XenApp Viewer, Citrix ICA Viewer, NICE DCV, VMware Fusion, and UTM, and hide McAfee Safari Host always. Reference: `src/preferences/Preferences.swift`.
- Legacy exception preferences are migrated into the current structured exception shape, including window-title patterns. References: `src/preferences/PreferencesMigrations.swift`, `src/preferences/PreferencesMigrationsSpecs.md`.

## Focus Sets

- Focus Sets are named collections of apps with optional direct keyboard shortcuts. They open the ordinary switcher grid scoped to that set's app membership; there is no runtime Focus Sets browser or parent-return flow. References: `src/switcher/focus-sets/FocusSet.swift`, `src/switcher/focus-sets/FocusSetSessionResolver.swift`, `src/switcher/focus-sets/AGENTS.md`.
- Persistence lives in a dedicated `focusSets` JSON value owned by `FocusSetsStore`, independent of the generic preference cache so malformed values never force a preference reset. References: `src/switcher/focus-sets/FocusSetsStore.swift`, `src/switcher/focus-sets/FocusSetsStoreSpecs.md`.
- Membership matching is exact non-empty bundle-identifier equality within a selected set (OR across rules). Cached app names are presentation-only; stored `titleContains` is currently inert. References: `src/switcher/focus-sets/FocusSetResolver.swift`, `src/switcher/focus-sets/FocusSetResolverSpecs.md`.
- Direct shortcuts require exactly one modifier and one non-modifier key, are keyed by the set's stable UUID, and apply the Focus Sets-global Focus / Hold / Search release style (`focusSetsShortcutStyle`) when all bound modifiers release. Repeating the active set shortcut cycles that scoped grid. References: `src/switcher/focus-sets/FocusSet.swift`, `src/switcher/focus-sets/FocusSetSessionResolver.swift`, `src/preferences/MacroPreferences.swift`.
- Window visibility for Focus Set sessions uses the shared filter pipeline plus a Focus Sets presentation policy and set membership — not a forked filter path. References: `src/switcher/focus-sets/FocusSet.swift`, `src/switcher/state/WindowFilterResolver.swift`, `src/switcher/state/Windows.swift`.
- The Focus Sets settings tab has Manager and Behavior segments: create/edit/delete/reorder sets, assign apps and optional shortcuts in one transactional sheet, and configure the shared release style. References: `src/switcher/focus-sets/FocusSetSettingsView.swift`, `src/switcher/focus-sets/FocusSetSettingsResolver.swift`, `src/preferences/settings-window/SettingsWindow.swift`.
- Stale or deleted set UUIDs never alias another set; removing the active direct set dismisses the switcher safely. Reference: `src/switcher/focus-sets/FocusSetSessionResolverSpecs.md`.

## Settings Window

- The Settings window has five sidebar sections: Appearance, Controls, Focus Sets, General, and Exceptions. About and Acknowledgments are shown in a separate About window, not the Settings sidebar. References: `src/preferences/settings-window/SettingsWindow.swift`, `src/preferences/settings-window/tabs/*`, `src/switcher/focus-sets/FocusSetSettingsView.swift`, `src/preferences/settings-window/tabs/AboutTab.swift`.
- Settings has a sidebar search that filters sections and highlights matching controls, segmented controls, popovers, sheets, and lazily built panes. References: `src/preferences/settings-window/SettingsSearch.swift`, `src/preferences/settings-window/SettingsSearchIndex.swift`, `src/preferences/settings-window/SettingsSectionSearchContent.swift`, `src/preferences/settings-window/SettingsSearchHighlight.swift`, `src/preferences/settings-window/SettingsSectionSearchContentSpecs.md`, `src/preferences/settings-window/SettingsSearchHighlightSpecs.md`.
- Settings search folds case, diacritics, and width; ignores whitespace, punctuation, and symbols; uses exact, prefix, fuzzy, and LCS-style scoring; and has stricter matching for 1-2 character queries. Reference: `src/preferences/settings-window/SettingsSearch.swift`.
- Appearance settings configure style, size, theme, target screen, title display, title truncation, and a customization sheet. The tab includes a live animated preview pane that cycles the selection highlight across demo app tiles once per second so the user can see how the chosen style looks without opening the switcher. The preview pauses automatically when the switcher is active, when the Settings window is hidden, or when the system Reduce Motion accessibility setting is on; users can also pause/resume it manually with a dedicated button. References: `src/preferences/settings-window/tabs/appearance/AppearanceTab.swift`, `src/preferences/settings-window/tabs/appearance/CustomizeStyleSheet.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceLivePreviewView.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceLivePreviewArtwork.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceLivePreviewResolver.swift`.
- Controls settings configure shortcut count, per-shortcut trigger/filtering/appearance/ordering tabs, and Advanced (Shortcuts When Active only). The Gestures category is built only when `FeatureFlags.gestures` is true. References: `src/preferences/settings-window/tabs/controls/ControlsTab.swift`, `src/preferences/settings-window/tabs/controls/ShortcutEditor.swift`, `src/preferences/settings-window/tabs/controls/ShortcutsWhenActiveSheet.swift`, `src/preferences/Preferences.swift`.
- The shortcut editor is recycled and lazily builds its Filtering, Appearance, and Ordering panes to reduce AppKit layout cost. Reference: `src/preferences/settings-window/tabs/controls/ShortcutEditor.swift`.
- Global Appearance values can be overridden per shortcut for style, size, theme, and shortcut release style. Selecting the current global value removes an override and resumes global synchronization. Changing a global value with matching shortcut overrides asks whether to remove those overrides for all shortcuts or preserve them; that dialog has a "do not ask again" suppression checkbox, and checking it persists the chosen answer so later changes replay it silently instead of prompting again. References: `src/preferences/Preferences.swift`, `src/preferences/settings-window/tabs/appearance/AppearanceTab.swift`, `src/preferences/settings-window/tabs/appearance/GlobalAppearanceChangeResolver.swift`, `src/preferences/settings-window/tabs/controls/ShortcutEditor.swift`, `src/preferences/settings-window/tabs/controls/OverrideClickResolver.swift`.
- Settings supports deep-link routing: any component can navigate to a specific page, shortcut editor pane (Trigger / Filtering / Appearance / Ordering), gesture profile (when gestures are enabled), Focus Sets, active-shortcuts (Advanced), exception by bundle identifier, or a search query. The `SettingsNavigationController` tracks the active route and the last non-search route so the view restores correctly when search is cleared. References: `src/preferences/settings-window/SettingsRoute.swift`, `src/preferences/settings-window/SettingsRouteSpecs.md`, `src/preferences/settings-window/SettingsWindow.swift`.
- General settings include start at login, show menu bar icon, language, update policy, manual update check, crash reports policy, export settings, import settings, and reset settings and restart. Start at login is implemented by writing/removing `~/Library/LaunchAgents/<bundle-id>.plist` and migrates/removes legacy `LSSharedFileList` login items. The written plist sets `ProgramArguments` (executable path plus `--scrytab-silent-launch`, so a login launch opens no window), `RunAtLoad`, `LimitLoadToSessionType: Aqua`, `AssociatedBundleIdentifiers`, `ProcessType: Interactive` (to avoid CPU throttling), and `LegacyTimers: true`. References: `src/preferences/settings-window/tabs/GeneralTab.swift`, `src/preferences/MenubarVisibilityPreference.swift`, `src/preferences/Preferences.swift`, `src/macos/LoginItem.swift`.
- Language options are System Default, German, English, Spanish, French, Japanese, Simplified Chinese, and Russian. Reference: `src/preferences/MacroPreferences.swift`.
- Changing language writes `AppleLanguages` and offers Restart Now or Later. Reference: `src/preferences/settings-window/tabs/GeneralTab.swift`.
- Update policy options are manual/no periodic checks, periodic checks, and periodic auto-install. References: `src/preferences/MacroPreferences.swift`, `src/vendors/SparkleDelegate.swift`.
- Crash report policy options are Never, Ask, and Always. References: `src/preferences/MacroPreferences.swift`, `src/vendors/SentryCrashReporter.swift`.
- Export settings writes a plist containing only ScryTab-owned preference keys. Import settings accepts a plist, filters to owned keys, writes the preference domain, and offers restart. Reference: `src/preferences/settings-window/tabs/GeneralTab.swift`, `src/preferences/Preferences.swift`.
- Reset settings clears ScryTab preferences and restarts after destructive confirmation. Reference: `src/preferences/settings-window/tabs/GeneralTab.swift`.

## Updates, Crash Reports, And Feedback

- Sparkle handles update checks. The updater is created at launch and started after 30 seconds; manual checks can start it earlier. References: `src/App.swift`, `src/vendors/SparkleDelegate.swift`, `src/preferences/settings-window/tabs/GeneralTab.swift`.
- Sparkle feed requests include app version, macOS version, architecture, and language as feed parameters. Reference: `src/vendors/SparkleDelegate.swift`.
- The update policy is kept in sync bidirectionally with Sparkle's own defaults: the app observes Sparkle's `SUEnableAutomaticChecks` and `SUAutomaticallyUpdate` keys and maps changes back to ScryTab's `updatePolicy`, while ScryTab-initiated policy changes set a `policyLock` to prevent the observer from echoing the change back into a loop. References: `src/events/UserDefaultsEvents.swift`, `src/events/PreferencesEvents.swift`, `src/preferences/settings-window/tabs/GeneralTab.swift`.
- Crash reporting uses Sentry in an explicit crash-only configuration; performance, profiling, replay, breadcrumbs, sessions, user identity, and automatic DebugProfile attachments are disabled. Reference: `src/vendors/SentryCrashReporter.swift`.
- Crash reports can be never sent, always sent, or asked before Sentry starts. Choosing Enable persists Always and starts reporting in the current launch; Not now persists Never. References: `src/App.swift`, `src/vendors/SentryCrashReporter.swift`.
- DebugProfile remains part of the explicit manual-feedback workflow only. Reference: `src/secondary-windows/DebugProfile.swift`.
- Feedback starts with a kind picker: Report a bug or Suggest a change. The picker has a single "View existing discussions" link that points to the GitHub issues page, and the form has a Go back button to return to the picker while preserving each kind's draft. Reference: `src/secondary-windows/FeedbackWindow.swift`.
- Bug feedback first checks for updates. If a newer version is available, the user is prompted to update first or report on the current version. The check is cached for the app session and has a 5 second timeout. Reference: `src/secondary-windows/FeedbackWindow.swift`.
- Feedback drafts are preserved per kind until successful submission. Reference: `src/secondary-windows/FeedbackWindow.swift`.
- Feedback title/body length caps are 256 UTF-16 code units and 64 KiB UTF-16 code units. Reference: `src/secondary-windows/FeedbackWindow.swift`.
- Feedback can be submitted with the send button or Cmd-Return, posts to the backend, and preserves drafts on failure. References: `src/secondary-windows/FeedbackWindow.swift`, `src/api/Endpoints.swift`.

- The About window shows app icon, app name/version/copyright, website/source/support links, usage stats for past week/month/year, and acknowledgments access. The icon/name/version/copyright/links are built by `AboutTab`; the usage stats and acknowledgments are composed by `AboutWindow`. ## System Event Reactivity

- The app reacts to running application changes, dock changes, AX events, Spaces changes, screen changes, system appearance changes, system scroller style changes, input source changes, screen lock, sleep/wake, and user defaults changes. References: `src/events/RunningApplicationsEvents.swift`, `src/events/DockEvents.swift`, `src/events/AccessibilityEvents.swift`, `src/events/SpacesEvents.swift`, `src/events/ScreensEvents.swift`, `src/events/SystemAppearanceEvents.swift`, `src/events/SystemScrollerStyleEvents.swift`, `src/events/InputSourceEvents.swift`, `src/events/ScreenLockEvents.swift`, `src/events/SleepWakeEvents.swift`, `src/events/UserDefaultsEvents.swift`.

The trackpad gesture tap is included in that recovery path only when `FeatureFlags.gestures` is true. References: `src/events/SleepWakeEvents.swift`, `src/events/ScreenLockEvents.swift`, `src/events/ScrollwheelEvents.swift`, `src/events/KeyboardEvents.swift`, `src/events/CursorEvents.swift`, `src/events/TrackpadEvents.swift`.
- Preference changes refresh affected controls, event taps, global shortcuts, native Command-Tab state, menubar state, Sparkle policy, settings UI, and switcher components. Reference: `src/events/PreferencesEvents.swift`.
- Background scheduling uses throttling and retry/backoff policies for expensive or bursty work. References: `src/util/Throttler.swift`, `src/util/SchedulingPolicy.swift`, `src/util/SchedulingPolicySpecs.md`.
